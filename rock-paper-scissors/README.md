# 📝 To-Do List App (Python)

A simple To-Do List application built using Python and Tkinter.
Tasks are saved in a text file so they are not lost after closing the app.

## Files
- `todo-list.py` → Main program
- `data.txt` → Stores tasks

## Features
- Add tasks
- Delete tasks
- Save tasks automatically

## Concepts Used
- File handling
- Tkinter GUI
- Listbox widget

## How to Run
```bash
python todo-list.py
