# 🐍 Python Beginner Projects

This repository contains a collection of **beginner-friendly Python projects** created to practice core programming concepts and build a strong foundation in Python.

These projects are ideal for students and beginners who want to improve logic, problem-solving skills, and hands-on coding experience.

---

## 📌 Projects Included

### 🔰 Beginner Level
- ✅ Calculator (CLI / GUI)
- ✅ To-Do List App
- ✅ Rock-Paper-Scissors Game
- ✅ Age & BMI Checker
- ✅ Unit Converter

Each project is placed in a **separate folder** with its own source code and README file.

## 🛠️ Technologies Used
- Python 3
- Basic Python libraries
- Command Line Interface (CLI)
- File Handling (in some projects)
